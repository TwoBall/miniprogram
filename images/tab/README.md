# 图标资源说明

本目录需要添加以下图标文件：

## 底部导航栏图标

### 1. attendance.png
- 用途：点名标签页图标（未选中状态）
- 尺寸：81px × 81px
- 格式：PNG
- 建议：使用签到、打卡相关图标

### 2. attendance-active.png
- 用途：点名标签页图标（选中状态）
- 尺寸：81px × 81px
- 格式：PNG
- 建议：与 attendance.png 相同图标，使用高亮颜色（#1890ff）

### 3. history.png
- 用途：历史记录标签页图标（未选中状态）
- 尺寸：81px × 81px
- 格式：PNG
- 建议：使用时钟、历史记录相关图标

### 4. history-active.png
- 用途：历史记录标签页图标（选中状态）
- 尺寸：81px × 81px
- 格式：PNG
- 建议：与 history.png 相同图标，使用高亮颜色（#1890ff）

## 应用Logo

### 5. logo.png
- 用途：登录页面显示的应用Logo
- 尺寸：建议 200px × 200px 或更大
- 格式：PNG（支持透明背景）
- 建议：使用学校或社团相关的标志性图标

## 图标获取方式

1. **使用图标库**：
   - iconfont（阿里巴巴矢量图标库）：https://www.iconfont.cn/
   - IconPark（字节跳动图标库）：https://iconpark.oceanengine.com/
   - Flaticon：https://www.flaticon.com/

2. **自行设计**：
   - 使用 Figma、Sketch、Adobe Illustrator 等设计工具
   - 导出为 PNG 格式，确保尺寸正确

3. **临时占位**：
   - 可以先使用纯色方块作为占位符
   - 后续再替换为正式图标

## 注意事项

- 所有图标必须符合微信小程序规范
- 图标文件大小建议控制在 40KB 以内
- 确保图标清晰，在不同设备上显示正常
- 选中和未选中状态的图标应保持一致的视觉风格

## 快速生成占位图标

如果暂时没有图标资源，可以使用以下方式生成简单的占位图标：

1. 使用在线工具：https://placeholder.com/
2. 使用 Photoshop 或其他图像编辑软件创建纯色图标
3. 从免费图标网站下载相似图标
