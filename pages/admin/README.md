## 架构说明

管理员分包模块包含系统管理员专用的功能页面，提供用户管理、审批管理、数据统计等核心管理功能。

## 目录结构

### 页面
- `approval/` - 审批管理页面，处理用户注册申请的审批和拒绝
- `home/` - 管理员首页，展示系统概览和快捷入口
- `profile/` - 管理员个人中心页面
- `users/` - 用户管理页面，支持用户的增删改查和状态管理
- `data/` - 数据中心页面，展示用户、学生、考勤等统计数据

## 功能说明

### 用户管理 (users)
- 按角色筛选用户列表
- 搜索用户（姓名、学部、班级、社团）
- 添加预注册用户
- 编辑用户信息
- 删除用户（软删除）
- 区分已绑定微信和预注册账号（通过 `_openid` 字段判断）

### 数据中心 (data)
- 用户统计：按角色、状态统计用户数量
- 学生统计：按学部、年级统计学生数量
- 考勤统计：出勤率、缺勤率等数据

### 审批管理 (approval)
- 查看待审批的注册申请
- 批量审批或拒绝申请
- 查看已处理的申请记录
