# 社团点名系统

一个基于微信小程序和云开发的校内社团点名管理系统，支持社团老师快捷点名、班主任实时查看学生到课情况、学部领导查看全学部考勤统计。

## 功能特点

### 三种角色权限

1. **社团老师**
   - 快速点名（到课/缺课/一键全到）
   - 查看历史点名记录
   - 实时统计到课率
   - 接收班主任反馈

2. **班主任**
   - 实时查看本班学生到课情况（优先显示缺课）
   - 按日期查询考勤记录
   - 对缺课学生发送反馈
   - 隐藏敏感信息（姓名/电话）

3. **学部领导**
   - 查看本学部所有班级考勤统计
   - 查看各班级出勤率
   - 查看班级详细考勤情况及反馈
   - 智能排序（缺课优先）

### 核心功能

- 用户注册与权限分配
- 社团学生管理
- 实时点名记录
- 考勤数据统计
- 多维度数据查看
- 反馈沟通机制（全角色互通）

## 技术栈

- **前端**：微信小程序（WXML + WXSS + JavaScript）
- **后端**：微信云开发
- **数据库**：云数据库
- **云函数**：Node.js

## 快速开始

### 1. 环境准备

- 安装微信开发者工具
- 注册微信小程序账号
- 开通云开发服务

### 2. 克隆项目

将项目文件复制到本地目录。

### 3. 配置云开发

1. 在微信开发者工具中打开项目
2. 开通云开发并创建环境
3. 修改 `app.js` 中的环境ID：

```javascript
wx.cloud.init({
  env: 'your-env-id', // 替换为您的云开发环境ID
  traceUser: true,
})
```

### 4. 创建数据库

在云开发控制台创建以下集合：
- `users` - 用户表
- `students` - 学生表
- `attendance_records` - 点名记录表
- `feedbacks` - 反馈表

详细结构请参考 [DATABASE.md](DATABASE.md)

### 5. 部署云函数

右键点击每个云函数文件夹，选择"上传并部署：云端安装依赖"：
- user
- students
- attendance
- submitFeedback

### 6. 导入学生数据

参考 [DATABASE.md](DATABASE.md) 中的数据导入说明，将学生数据导入数据库。

### 7. 准备图标资源

在 `images/tab/` 目录下添加以下图标：
- attendance.png / attendance-active.png
- history.png / history-active.png
- logo.png

### 8. 编译运行

点击"编译"按钮，预览小程序。

## 使用流程

### 初次使用

1. 用户打开小程序，进入注册页面
2. 填写个人信息并选择角色（社团老师/班主任/学部领导）
3. 根据角色填写对应信息（社团名称/班级/学部）
4. 注册成功后自动跳转到对应角色的首页

### 社团老师点名

1. 登录后进入点名页面
2. 查看社团学生列表
3. 对每个学生标记"到课"或"缺课"（或点击"一键全到"）
4. 提交点名记录

### 班主任查看

1. 登录后进入班级概览页面
2. 选择日期查看考勤情况
3. 查看学生到课/缺课状态（缺课置顶）
4. 对缺课学生发送反馈

### 学部领导查看

1. 登录后进入学部仪表盘
2. 查看各班级考勤统计
3. 点击班级查看详细情况（可查看班主任反馈）
4. 按日期筛选数据
