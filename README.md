# 社团点名系统

> 一个基于微信小程序和云开发的校内社团点名管理系统

[![版本](https://img.shields.io/badge/版本-v1.2.0-blue.svg)](https://github.com)
[![基础库](https://img.shields.io/badge/基础库-2.2.3+-green.svg)](https://developers.weixin.qq.com/miniprogram/dev/framework/)
[![许可证](https://img.shields.io/badge/许可证-MIT-orange.svg)](LICENSE)

## 📖 项目简介

社团点名系统是一个功能完善的校内社团考勤管理解决方案，支持社团老师快捷点名、班主任实时查看学生到课情况、学部领导查看全学部考勤统计。系统采用微信小程序原生框架开发，结合云开发技术，实现了高效、便捷的考勤管理。

## ✨ 核心特性

### 🎯 多角色权限管理

1. **社团老师**
   - 快速点名（到课/缺课/一键全到）
   - 查看历史点名记录
   - 实时统计到课率
   - 接收班主任反馈

2. **班主任**
   - 实时查看本班学生到课情况（优先显示缺课）
   - 按日期查询考勤记录
   - 对缺课学生发送反馈
   - 隐藏敏感信息（姓名/电话）

3. **学部领导**
   - 查看本学部所有班级考勤统计
   - 查看各班级出勤率
   - 查看班级详细考勤情况及反馈
   - 智能排序（缺课优先）

4. **系统管理员**
   - 审批用户注册申请
   - 管理用户权限
   - 查看已通过/已拒绝用户列表

### 💡 核心功能

- ✅ **用户认证**：微信登录、角色注册、权限审批
- ✅ **快速点名**：滑动点名、一键全到、撤销操作
- ✅ **实时统计**：自动计算到课率、缺课人数
- ✅ **数据查询**：按日期、班级、学部多维度查询
- ✅ **反馈机制**：班主任可对缺课学生发送反馈
- ✅ **角色切换**：支持一个用户拥有多个角色

## 🚀 快速开始

### 环境要求

- Node.js >= 14.0.0
- 微信开发者工具 >= 1.06.0
- 微信小程序账号（已开通云开发）

### 安装步骤

#### 1. 克隆项目

```bash
git clone <repository-url>
cd 我来点名啦
```

#### 2. 安装依赖

```bash
npm install
```

#### 3. 配置云开发

- 安装微信开发者工具
- 注册微信小程序账号
- 开通云开发服务


```javascript
wx.cloud.init({
  env: 'your-env-id', // 替换为您的云开发环境ID
  traceUser: true,
})
```

#### 4. 创建数据库集合

在云开发控制台创建以下集合：
- `users` - 用户表
- `students` - 学生表
- `attendance_records` - 点名记录表
- `feedbacks` - 反馈表

**详细字段说明请参考** → [数据库设计文档](DATABASE.md)

#### 5. 部署云函数

右键点击每个云函数文件夹，选择"上传并部署：云端安装依赖"：
- user
- students
- attendance
- submitFeedback

#### 6. 导入学生数据

```bash
cd tools
npm install
node convert.js
```

然后在云开发控制台导入生成的 JSON 文件。

**详细步骤请参考** → [数据库设计文档 - 数据导入](DATABASE.md#数据导入)

#### 7. 编译运行

在 `images/tab/` 目录下添加以下图标：
- attendance.png / attendance-active.png
- history.png / history-active.png
- logo.png

在微信开发者工具中点击"编译"按钮，预览小程序。

## 📱 使用指南

### 初次使用

1. 用户打开小程序，进入注册页面
2. 填写个人信息并选择角色（社团老师/班主任/学部领导）
3. 根据角色填写对应信息（社团名称/班级/学部）
4. 注册成功后自动跳转到对应角色的首页

### 社团老师点名

1. 登录后进入点名页面
2. 查看社团学生列表
3. 对每个学生标记"到课"或"缺课"（或点击"一键全到"）
4. 提交点名记录

### 班主任查看

1. 登录后进入班级概览页面
2. 选择日期查看考勤情况
3. 查看学生到课/缺课状态（缺课置顶）
4. 对缺课学生发送反馈

### 学部领导查看

1. 登录后进入学部仪表盘
2. 查看各班级考勤统计
3. 点击班级查看详细情况（可查看班主任反馈）
4. 按日期筛选数据
